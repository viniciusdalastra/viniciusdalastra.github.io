About

Engineering that holds up under scale

Senior Full-Stack Engineer with 10+ years building scalable, secure platforms across payments, SaaS, real-time messaging, e-commerce and public-sector systems. I have delivered solutions supporting 15,000+ concurrent users and backend messaging flows reaching hundreds of millions of interactions, and led payment systems processing R$1.8B+ in transactions.

My core stack is Node.js (TypeScript), NestJS and Express on the backend, Angular / React / Next.js on the frontend, with MongoDB, PostgreSQL and MS SQL Server, Docker, CI/CD and AWS & Azure. I work daily with microservices, REST and Graph APIs, event-driven architecture, webhooks and WebSockets.

I also build AI integrations (GPT API, agents, automation) and use AI-assisted development tools such as Claude Code and Lovable for coding, refactoring, testing and rapid prototyping.
